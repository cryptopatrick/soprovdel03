# SO-prov: Andra världskriget, del 3

Provet: https://cryptopatrick.github.io/soprovdel03/

**Del 3** täcker krigets konsekvenser, Nürnbergrättegångarna och Sverige under kriget:
- Dödsoffer, bombningar, flyktingar och kvinnornas situation
- Nürnbergrättegångarna och jakten på krigsförbrytare
- Sveriges neutralitet, handel och eftergifter (permittenttrafiken)
- Beredskapstiden, spioner i Stockholm
- Sveriges flyktingpolitik och de vita bussarna

20 frågor, 115 poäng, 75 minuter. Claude rättar med förklaringar.

- `pluggguide.md` – pluggguiden (samma format som del 1 och 2).
- `fragor.js` – frågor och facit.
- `index.html` – provsidan (GitHub Pages).
- `server/` – rättningsserver på VPS (soprov3.49-12-204-84.sslip.io, port 8794).

Uppdatera servern: `server/drift/deploy.sh`
